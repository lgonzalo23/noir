# Noir - CI/CD

Caso académico del curso Herramientas de Desarrollo.

## Estructura

- `src/`: programa Java del módulo de reservas.
- `test/`: pruebas automáticas.
- `public/`: frontend estático para el despliegue.
- `.github/workflows/`: flujos de Integración Continua, Control de Calidad y Despliegue Continuo.

## Flujo

develop → CI → Pull Request → QA → main → CD
